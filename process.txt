after segregating user and tasks into different service.

the first step for us is to build separate images of each service and load it into our kind cluster.

for now, we will just focus on bringing up the application level code, later we will database into our cluster as well.

to laod task service image into our cluster:-
- docker build -t tasks-service:1.0 ./tasks-service
- kind load docker-image tasks-service:1.0 --name todo-cluster

apply & testing commands for pods:-
- kubectl apply -f manifests/tasks-service.yml
- kubectl get pods
- kubectl port-forward svc/tasks-service 3001:3001

same for user service we will do!

- docker build -t user-service:1.0 ./user-service
- kind load docker-image user-service:1.0 --name todo-cluster

but in order for user-service to communicate with tasks service, we need tasks service url where it is running.
so it will be the cluster dns name of tasks service which will be the host of that service via which we can call task service processes.

then we apply the user-service

- kubectl apply -f manifests/user-service.yml
- kubectl get pods
- kubectl port-forward svc/user-service 3000:3000
